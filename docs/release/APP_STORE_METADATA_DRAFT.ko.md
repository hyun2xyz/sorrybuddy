## Full Description Draft

SorryBuddy는 오래 걸리는 로컬 작업을 할 때 상태를 확인하고, 작업을 안전하게 정리할 수 있도록 돕는 작은 macOS 메뉴바 앱입니다.

메뉴바에서 현재 상태를 확인하고, 배터리 상태를 점검하며, 작업을 계속해도 되는지 빠르게 판단할 수 있습니다.

주의:

- 이 앱은 하드웨어를 방치하기 위한 도구가 아닙니다.
- 맥북은 항상 통풍되는 책상 위에서 사용해야 합니다.
- 가방, 침대, 이불, 더운 장소, 직사광선 아래에서는 사용하지 마세요.
