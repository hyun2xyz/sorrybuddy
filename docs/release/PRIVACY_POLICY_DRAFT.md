# SorryBuddy Privacy Policy Draft

Effective date: not published

SorryBuddy is designed as a local macOS utility.

## Data Collection

SorryBuddy does not collect, sell, or share personal data.

## Local Device Data

SorryBuddy may read local power and battery status to show the current app state. This information stays on the user's device.

## Network Access

The direct-distribution build may contact GitHub Releases when the user chooses `업데이트 확인...`.

The App Store build should avoid external update checks because App Store apps are updated through the App Store.

## Contact

Support: https://github.com/hyun2xyz/sorrybuddy/issues
